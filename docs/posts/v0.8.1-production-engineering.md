# Obeserva v0.8.1 — Production Engineering

**Release date:** 2026-06-01  
**Install:** `composer require scout/laravel`

---

## Summary

**v0.8.1 — Production Engineering** hardens Obeserva for long-running PHP workers, Horizon processes, and Octane deployments with bounded in-memory buffers and exception-safe flush behavior.

## Highlights

### Memory safety

- **Completed span buffer** — `Tracer` auto-flushes when completed spans exceed `OBESERVA_MAX_COMPLETED_SPANS` (default `2048`)
- **Active span depth guard** — `ContextManager` ends the oldest active span when nesting exceeds `OBESERVA_MAX_ACTIVE_SPAN_DEPTH` (default `256`)
- **Trace snapshot bounds** — development `TraceSnapshotRegistry` evicts oldest entries at `OBESERVA_MAX_TRACE_SNAPSHOTS` (default `512`)
- **Memory pressure flush** — optional RSS threshold via `OBESERVA_MEMORY_PRESSURE_BYTES` triggers auto-flush

### Flush safety

- **`TracerFlushGuard`** — wraps tracer flush in try/catch so Scout/OTel export failures never break requests or jobs
- **Shutdown flush** — `ShutdownFlushRegistrar` registers a one-time `register_shutdown_function` handler
- **Worker stopping** — `FlushTracerOnWorkerStoppingListener` resets tracer state when queue workers shut down

## Configuration

| Variable | Default | Description |
|----------|---------|-------------|
| `OBESERVA_MAX_COMPLETED_SPANS` | `2048` | Completed span buffer limit before auto-flush |
| `OBESERVA_MAX_ACTIVE_SPAN_DEPTH` | `256` | Max active span nesting depth |
| `OBESERVA_MAX_TRACE_SNAPSHOTS` | `512` | Max development trace snapshots retained |
| `OBESERVA_MEMORY_PRESSURE_BYTES` | `0` | RSS threshold for auto-flush (`0` = disabled) |
| `OBESERVA_FLUSH_SAFETY` | `true` | Enable production flush safety features |
| `OBESERVA_FLUSH_GUARD_EXCEPTIONS` | `true` | Swallow exporter exceptions during flush |
| `OBESERVA_FLUSH_ON_SHUTDOWN` | `true` | Flush on PHP shutdown |
| `OBESERVA_FLUSH_ON_WORKER_STOPPING` | `true` | Flush when queue workers stop |

Config keys: `obeserva.memory.*`, `obeserva.flush.*`.
