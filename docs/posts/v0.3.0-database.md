# Obeserva v0.3.0 — Database Instrumentation

**Release date:** 2026-05-26  
**Install:** `composer require scout/laravel`

---

## Summary

**v0.3.0 — Database Instrumentation** adds automatic query tracing and N+1 pattern detection to the Laravel integration—every database query becomes a child span with sanitized SQL, timing, and connection metadata.

## Highlights

### Query tracing

Each `QueryExecuted` event creates a `db.{operation}` child span with:

- `db.system`, `db.connection`, `db.operation`
- `db.statement` (sanitized bindings, max 4KB)
- `db.duration_ms`
- `db.query_count` on the active HTTP span

### N+1 / lazy-load detection

`NPlusOneDetector` normalizes repeated SELECT patterns during a request. When the same pattern runs twice (configurable threshold), the active span receives:

- `n_plus_one_detected` span event
- `db.n_plus_one_detected` and `db.n_plus_one.pattern` attributes

Enable or disable via `OBESERVA_DB_LAZY_LOADING_DETECTION` (default `true`).

## Configuration

| Variable | Default | Description |
|----------|---------|-------------|
| `OBESERVA_DB_QUERY_TRACING` | `true` | Record `db.*` spans for queries |
| `OBESERVA_DB_LAZY_LOADING_DETECTION` | `true` | Detect repeated query patterns (N+1) |
