# Obeserva v0.5.0 — Scout APM Driver (preview)

**Target release:** v0.5.0  
**Install:** `composer require scout/laravel` + optional `scoutapp/scout-apm-laravel`

---

## Summary

**v0.5.0 — Scout Driver** exports Obeserva span lifecycle events to Scout APM when `OBESERVA_DRIVER=scout`. Internal instrumentation (HTTP, database, queue, cache, Redis, Horizon) stays vendor-neutral; the Scout driver translates spans at flush time.

## Highlights

### Span lifecycle export

`ScoutSpanExporter` implements `SpanLifecycleExporterInterface` and forwards span start/end events to the Scout agent. On flush, pending spans are sent via `ScoutApmClientInterface::send()`.

### Span mapping

`ScoutSpanMapper` maps Obeserva `SpanKind` values to Scout operation prefixes:

| Span kind | Scout operation prefix |
|-----------|------------------------|
| HTTP server/client | `HTTP/` |
| Database | `SQL/` |
| Queue | `Job/` |
| External | `External/` |
| Internal/custom | `Custom/` |

### Context bridge

`ScoutContextBridge` applies default tags from `obeserva.scout.default_tags` and propagates trace/span metadata as Scout request tags.

## Configuration

| Variable | Default | Description |
|----------|---------|-------------|
| `OBESERVA_DRIVER` | `noop` | Set to `scout` to enable export |
| `OBESERVA_SCOUT_ENABLED` | `true` | Toggle Scout export |
| `OBESERVA_SCOUT_APPLICATION_NAME` | `APP_NAME` | Scout application name |
| `OBESERVA_SCOUT_KEY` | `SCOUT_KEY` | Scout application key |
| `OBESERVA_SCOUT_MONITORING_ENABLED` | `SCOUT_MONITORING_ENABLED` | Scout monitoring toggle |
