# Obeserva v0.3.1 — Queue Instrumentation

**Release date:** 2026-05-26  
**Install:** `composer require scout/laravel`

---

## Summary

**v0.3.1 — Queue Instrumentation** propagates trace context from HTTP requests into queued jobs and records consumer spans for every job processed— including failed-job correlation back to the parent trace.

## Highlights

### Trace propagation

When a job is dispatched during an active trace, Obeserva injects W3C `traceparent` metadata into the queue payload via Laravel's `Queue::createPayloadUsing` hook. Workers restore context before processing.

### Job consumer spans

Each job creates a `queue.process:{JobClass}` consumer span with:

- `queue.connection`, `queue.name`, `queue.job`, `queue.uuid`
- `messaging.system`, `messaging.operation`
- `trace.parent_trace_id` linking to the dispatching request

### Failed job correlation

`JobFailed` events enrich the active job span with exception metadata and mark `queue.result=failed`, preserving causation visibility in traces.

## Configuration

| Variable | Default | Description |
|----------|---------|-------------|
| `OBESERVA_QUEUE_PROPAGATION` | `true` | Inject trace context into payloads |
| `OBESERVA_QUEUE_JOB_TRACING` | `true` | Consumer spans for job processing |
| `OBESERVA_QUEUE_FAILED_CORRELATION` | `true` | Failed job exception correlation |
