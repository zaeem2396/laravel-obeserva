# Obeserva v0.7.0 — Developer Experience (Telescope & Debug Toolbar)

**Release date:** 2026-05-29  
**Install:** `composer require scout/laravel` + optional `laravel/telescope`

---

## Summary

**v0.7.0 — Developer Experience** adds local trace inspection for Laravel development: span snapshots, a debug toolbar, and optional Telescope publishing — without changing your production driver (`noop`, `scout`, or `otel`).

## Highlights

### Trace snapshots

Completed spans are captured as immutable `TraceSnapshot` values in a request-scoped `TraceSnapshotRegistry` via `SpanSnapshotCollector`. The collector runs alongside your configured driver through `CompositeSpanLifecycleExporter`.

### Debug toolbar

When `OBESERVA_DEBUG_TOOLBAR=true` (defaults to local + `APP_DEBUG`), `DebugToolbarMiddleware` injects a fixed HTML panel at the bottom of HTML responses showing:

- Span count and total duration
- Hierarchical span tree with kind and timing
- Queue and HTTP propagation summary

### Telescope integration

When `OBESERVA_TELESCOPE_ENABLED=true` and `laravel/telescope` is installed, `PublishTraceToTelescope` records span snapshots and propagation metadata to Telescope on request terminate.

## Configuration

| Variable | Default | Description |
|----------|---------|-------------|
| `OBESERVA_TELESCOPE_ENABLED` | `false` | Publish span snapshots to Telescope on terminate |
| `OBESERVA_DEBUG_TOOLBAR` | local + `APP_DEBUG` | Inject HTML trace toolbar into responses |
| `OBESERVA_DEBUG_TOOLBAR_PROPAGATION` | `true` | Show queue/HTTP propagation summary in toolbar |

Config keys: `obeserva.development.*` in `config/obeserva.php`.
