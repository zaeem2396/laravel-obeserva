# Obeserva v0.4.1 — Cache & Redis Instrumentation

**Release date:** 2026-05-28  
**Install:** `composer require scout/laravel`

---

## Summary

**v0.4.1 — Cache & Redis Instrumentation** adds Laravel cache store spans (hit, miss, write, forget) and Redis command spans with connection metadata and latency—completing the runtime coverage started in v0.3.x–v0.4.0 for HTTP, database, queue, and Horizon.

## Highlights

### Cache store hooks

`TraceCacheEventListener` listens to Laravel cache events and records client spans:

| Event | Span name | Attributes |
|-------|-----------|------------|
| `CacheHit` | `cache.get` | `cache.store`, `cache.key`, `cache.hit=true` |
| `CacheMissed` | `cache.miss` | `cache.store`, `cache.key`, `cache.hit=false` |
| `KeyWritten` | `cache.put` | `cache.store`, `cache.key`, `cache.ttl_seconds` |
| `KeyForgotten` | `cache.forget` | `cache.store`, `cache.key` |

Works with any cache driver that fires Laravel's standard cache events (array, file, Redis, Memcached, etc.).

### Redis command tracing

`TraceRedisCommandExecutedListener` hooks `Illuminate\Redis\Events\CommandExecuted` and records `redis.{command}` spans with:

- `db.system=redis`
- `db.operation` (lowercased command name)
- `db.connection` (connection name)
- `db.duration_ms`

## Configuration

| Variable | Default | Description |
|----------|---------|-------------|
| `OBESERVA_CACHE_ENABLED` | `true` | Cache hit/miss/write/forget spans |
| `OBESERVA_REDIS_COMMAND_TRACING` | `true` | Redis `CommandExecuted` spans |

Config keys: `obeserva.cache.enabled`, `obeserva.redis.command_tracing` in `config/obeserva.php`.
