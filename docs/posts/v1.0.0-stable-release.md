# Obeserva v1.0.0 — Stable Release (Preview)

**Target release date:** 2026-06-03  
**Install:** `composer require scout/laravel`

---

## Summary

**v1.0.0 — Stable Release** marks production stabilization and enterprise-grade API guarantees. Obeserva is ready for long-term adoption with semver-backed contracts, runtime diagnostics, and Scout partnership documentation.

## Highlights

### API stability

`Obeserva\Contracts` interfaces are semver-stable for the 1.x line. See [API stability policy](../API_STABILITY.md) and [upgrade guide](../UPGRADE.md).

### Runtime diagnostics

`php artisan obeserva:status` reports package version, driver, worker runtime, enabled features, and memory/flush configuration. JSON output is available for automation:

```bash
php artisan obeserva:status --json
```

### Configuration validation

Optional strict mode (`OBESERVA_CONFIG_STRICT=true`) fails fast on invalid driver or sample-rate configuration during application boot.

### Scout partnership readiness

- `scout.obeserva.version` tag on Scout exports
- [Scout integration guide](../SCOUT_INTEGRATION.md)
- [Benchmark documentation](../BENCHMARKS.md)

## Configuration

| Variable | Default | Description |
|----------|---------|-------------|
| `OBESERVA_STATUS_COMMAND` | `true` | Register `obeserva:status` artisan command |
| `OBESERVA_CONFIG_STRICT` | `false` | Throw on invalid configuration at boot |

Config keys: `obeserva.diagnostics.*`, `obeserva.validation.*`.

## What's next

Post-1.0 work focuses on Octane CI runtime tests, Docker integration tests, and OpenTelemetry compliance validation.
