# Obeserva v0.2.0 — Core Runtime

**Release date:** 2026-05-26  
**Install:** `composer require scout/laravel`

---

## Summary

**v0.2.0 — Core Runtime** delivers the instrumentation engine that turns Obeserva from a scaffold into a working tracing runtime: nested spans, request-scoped context, lifecycle cleanup, and richer HTTP observability.

## Highlights

### Span lifecycle engine

- Parent-child span nesting with shared `trace_id`
- `ActiveSpanStorageInterface` and active span stack on `ContextManager`
- Idempotent `Span::end()` with duration calculation
- Completed-span buffer on `Tracer` for export hooks via `flush()`
- `SpanScope` / `Tracer::trace()` for automatic span completion

### HTTP instrumentation

`TraceRequestMiddleware` now records:

- `http.duration_ms`, `http.url`, `laravel.route.name`
- `user.id` when authenticated
- `exception.type` and `exception.message` on failures
- Incoming W3C `traceparent` propagation (from v0.1.0)

### Developer experience

- `FakeTracer` supports nested spans for package tests
- 15 PHPUnit tests across contracts, core, laravel, and testing packages
- Middleware registers on `app->booted()` for reliable Testbench and Laravel compatibility

## Upgrade from v0.1.0

No breaking config changes. `SpanInterface` gains new methods; custom span implementations must implement trace identity and duration accessors.

## What's next

**v0.2.1** deepens Laravel HTTP instrumentation. **v0.3.0** adds database query tracing and lazy-load detection—the next major visibility win for Laravel apps.
