# Obeserva v0.2.1 — Laravel HTTP

**Release date:** 2026-05-26  
**Install:** `composer require scout/laravel`

---

## Summary

**v0.2.1 — Laravel HTTP** completes the Laravel integration milestone from the roadmap: production-grade HTTP request spans, route and middleware metadata, exception correlation, and optional pipeline timing middleware.

## Highlights

### HTTP request spans

- Centralized enrichment via `RequestSpanEnricher`
- Client metadata: IP, user agent, scheme, host
- Response metadata: status, content type, content length
- Authenticated user id and model class
- Lifecycle span events: `request.received`, `response.sent`

### Route instrumentation

On `RouteMatched`, active request spans receive:

- `laravel.route.name`, `laravel.route.action`
- `laravel.middleware.stack` (comma-separated)
- `route.matched` span event

### Exception instrumentation

Reported exceptions attach to the active HTTP span when present. Outside a request, a dedicated `exception` span is created automatically via Laravel's `reportable()` hook.

### Middleware timing

Register pipeline segment timing with the `obeserva.timing` alias:

```php
Route::middleware('obeserva.timing:api')->group(function () {
    // routes...
});
```

Each segment records a child span `middleware.{name}` with duration in milliseconds.

### Terminate flush

Completed spans are flushed when the application terminates (`OBESERVA_FLUSH_ON_TERMINATE`, default `true`), preparing for future driver export.

## Configuration

| Variable | Default | Description |
|----------|---------|-------------|
| `OBESERVA_EXCEPTION_INSTRUMENTATION` | `true` | Reportable exception hooks |
| `OBESERVA_FLUSH_ON_TERMINATE` | `true` | Flush tracer on terminate |
| `OBESERVA_HTTP_MIDDLEWARE_TIMING` | `true` | Register `obeserva.timing` alias |
