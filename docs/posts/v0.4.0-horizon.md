# Obeserva v0.4.0 — Horizon Integration

**Release date:** 2026-05-26  
**Install:** `composer require scout/laravel`  
**Optional:** `composer require laravel/horizon`

---

## Summary

**v0.4.0 — Horizon Integration** adds optional Laravel Horizon instrumentation: supervisor worker lifecycle spans, throughput counters, and retry trace correlation across Horizon-managed Redis queues.

## Highlights

### Worker lifecycle tracing

When Horizon is installed, Obeserva listens for:

- `SupervisorLooped` — long-lived `horizon.supervisor:{name}` internal spans with rolling metrics
- `WorkerProcessRestarting` / `SupervisorProcessRestarting` — restart spans
- `WorkerStopping` — graceful supervisor span shutdown

### Throughput metrics

Horizon `JobReserved` and `JobReleased` events increment counters exposed as span attributes:

- `horizon.jobs_reserved`
- `horizon.jobs_released`
- `horizon.worker_restarts`
- `horizon.supervisor_restarts`

### Retry trace correlation

Queue payloads now carry `root_trace_id` for causation chains. Job spans include:

- `trace.root_trace_id`
- `queue.retry_attempt`
- `horizon.retry_of` (when Horizon marks a retry)

## Configuration

| Variable | Default | Description |
|----------|---------|-------------|
| `OBESERVA_HORIZON_ENABLED` | `true` | Master switch (no-op without Horizon installed) |
| `OBESERVA_HORIZON_WORKER_TRACING` | `true` | Supervisor/worker lifecycle spans |
| `OBESERVA_HORIZON_THROUGHPUT_METRICS` | `true` | Reserved/released job counters |
| `OBESERVA_HORIZON_RETRY_CORRELATION` | `true` | Root trace + retry attempt attributes |
