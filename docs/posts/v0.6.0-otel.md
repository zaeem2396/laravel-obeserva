# Obeserva v0.6.0 — OpenTelemetry Alignment

**Release date:** 2026-06-14  
**Install:** `composer require scout/laravel` + optional `open-telemetry/opentelemetry`

---

## Summary

**v0.6.0 — OpenTelemetry Alignment** adds an OTel export driver and semantic convention normalization. Laravel instrumentation stays unchanged; spans are converted to OTel-compatible payloads at flush time when `OBESERVA_DRIVER=otel`.

## Highlights

### Semantic conventions

`OtelSemanticConventionMapper` aligns existing span attributes to OTel keys:

| Source attribute | OTel attribute |
|------------------|----------------|
| `http.method` | `http.request.method` |
| `http.status_code` | `http.response.status_code` |
| `db.statement` | `db.query.text` |
| `queue.name` | `messaging.destination.name` |
| `queue.job` | `messaging.operation.name` |

### Span conversion

`OtelSpanConverter` produces export payloads with:

- W3C-compatible trace and span IDs
- OTel span kind constants (`SPAN_KIND_SERVER`, etc.)
- Unix nano start/end timestamps
- `service.name` and `service.version` resource attributes

### Driver selection

`LifecycleExporterResolver` routes lifecycle export to Scout (`scout`), OTel (`otel`), or noop (`noop`) based on `OBESERVA_DRIVER`.

## Configuration

| Variable | Default | Description |
|----------|---------|-------------|
| `OBESERVA_DRIVER` | `noop` | Set to `otel` to enable OTel export |
| `OBESERVA_OTEL_ENABLED` | `true` | Toggle OTel export |
| `OBESERVA_OTEL_SERVICE_NAME` | `APP_NAME` | Service name resource attribute |
| `OBESERVA_OTEL_SERVICE_VERSION` | `APP_VERSION` | Service version resource attribute |
| `OBESERVA_OTEL_SEMANTIC_CONVENTIONS` | `true` | Normalize attributes to OTel conventions |

Config keys: `obeserva.otel.*` in `config/obeserva.php`.
