# Obeserva v0.9.0 — AI/Advanced Features

**Release date:** 2026-06-02  
**Install:** `composer require scout/laravel`

---

## Summary

**v0.9.0 — AI/Advanced Features** adds structured trace summaries and slow-request causation graphs — optimized for debugging workflows and future LLM-assisted incident analysis.

## Highlights

### Trace summaries

`TraceSummaryBuilder` produces a compact, JSON-serializable summary from completed span snapshots:

- Span counts grouped by category (HTTP, database, cache, queue, events, and more)
- Top slow spans ranked by duration
- Propagation context (queue/HTTP flows, parent context)
- Optional causation graph attachment

Summaries are built on application terminate and stored in `TraceSummaryRegistry` for programmatic access via `obeservaTraceSummary()` in tests.

### Slow-request causation

When request duration exceeds `OBESERVA_SLOW_REQUEST_THRESHOLD_MS` (default `1000` ms), `SlowRequestAnalyzer` identifies root-cause spans — typically the slowest database, cache, or queue children.

`CausationGraphBuilder` constructs a parent-child graph with `root_cause_span_ids` for quick attribution in the debug toolbar, Telescope, or exported JSON.

## Configuration

| Variable | Default | Description |
|----------|---------|-------------|
| `OBESERVA_TRACE_SUMMARIES` | `true` | Enable trace summary generation on terminate |
| `OBESERVA_SUMMARY_TOP_SLOW_SPANS` | `5` | Number of slow spans included in summaries (`0` disables) |
| `OBESERVA_CAUSATION_ENABLED` | `true` | Build causation graphs for summaries |
| `OBESERVA_SLOW_REQUEST_THRESHOLD_MS` | `1000` | Mark requests slower than this threshold |

Config keys: `obeserva.summaries.*`, `obeserva.causation.*`.

## Example

```php
use Obeserva\Testing\TraceSummaryAssert;

$summary = $this->obeservaTraceSummary();

TraceSummaryAssert::assertSlowRequest($summary);
TraceSummaryAssert::assertHasRootCause($summary);

echo json_encode($summary->toArray(), JSON_PRETTY_PRINT);
```
