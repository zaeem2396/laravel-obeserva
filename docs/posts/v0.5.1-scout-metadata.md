# Obeserva v0.5.1 — Advanced Scout Metadata

**Release date:** 2026-06-14  
**Install:** `composer require scout/laravel` + optional `scoutapp/scout-apm-laravel`

---

## Summary

**v0.5.1 — Advanced Scout Metadata** enriches Scout APM exports with Laravel-aware `scout.*` tags: named routes, queue jobs, Horizon supervisors, deployment version, tenant ID, and PHP/Laravel runtime diagnostics.

## Highlights

### Span metadata mapping

`ScoutSpanMetadataMapper` promotes instrumentation attributes to Scout tags:

| Source attribute | Scout tag |
|------------------|-----------|
| `laravel.route.name` | `scout.route.name` |
| `laravel.route.action` | `scout.route.action` |
| `http.route` | `scout.route.uri` |
| `queue.name` / `queue.job` | `scout.queue.name` / `scout.queue.job` |
| `horizon.supervisor` / `horizon.job_id` | `scout.horizon.supervisor` / `scout.horizon.job_id` |

### Runtime diagnostics

`ScoutRuntimeDiagnostics` tags each export with `scout.php.version`, `scout.laravel.version`, `scout.app.env`, and `scout.app.debug`.

### Config-driven metadata

| Variable | Default | Description |
|----------|---------|-------------|
| `OBESERVA_SCOUT_DEPLOYMENT_VERSION` | `APP_VERSION` | Build/deployment version |
| `OBESERVA_SCOUT_TENANT_ID` | _(empty)_ | Tenant identifier |
| `OBESERVA_SCOUT_METADATA_ENABLED` | `true` | Toggle metadata enrichment |

Config keys: `obeserva.scout.deployment_version`, `tenant_id`, `metadata_enabled` in `config/obeserva.php`.
