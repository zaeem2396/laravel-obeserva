# Obeserva v0.7.1 — Testing Utilities

**Release date:** 2026-05-30  
**Install:** `composer require scout/laravel`

---

## Summary

**v0.7.1 — Testing Utilities** completes the developer-experience testing story for Obeserva. Package and application tests can assert trace propagation, span hierarchies, and snapshot flows without standing up a full APM backend.

## Highlights

### Propagation assertions

`TraceContextAssert` verifies W3C `traceparent` headers and queue payload context injected by `TraceContextCarrier` — useful when testing job dispatch and async trace continuity.

### Snapshot helpers

`TraceSnapshotBuilder` creates fluent `TraceSnapshot` fixtures. `TraceSnapshotAssert` checks snapshot counts, attributes, parent/child relationships, and queue/HTTP propagation summaries via `PropagationFlowInspector`.

### Extended FakeTracer

`FakeTracer` now supports span lookup, count and attribute assertions, parent/child checks, and conversion to `TraceSnapshot` values through `spanSnapshots()`.

### Laravel test trait

`InteractsWithObeserva` swaps in `FakeTracer` during Orchestra Testbench tests and exposes helpers for Obeserva configuration and development snapshot collection.

### Benchmark suite

`scripts/benchmark-instrumentation.php` measures flat span overhead, nested span trees with `ContextManager`, and snapshot conversion — run locally or in the benchmark CI workflow.

## Example

```php
use Obeserva\Testing\FakeTracer;
use Obeserva\Testing\TraceContextAssert;
use Obeserva\Laravel\Queue\TraceContextCarrier;

$tracer = new FakeTracer;
$span = $tracer->startSpan('http.request');
$span->end();

$tracer->assertSpanRecorded('http.request');

$payload = TraceContextCarrier::inject($context, []);
TraceContextAssert::assertQueuePayloadContainsTraceId($payload, $context->getTraceId());
```
