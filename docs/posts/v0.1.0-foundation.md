# Obeserva v0.1.0 — Foundation

**Release date:** 2026-05-26  
**Install:** `composer require scout/laravel` (path / VCS until Packagist publish)

---

## Summary

We're shipping **v0.1.0 — Foundation**, the first public milestone of Obeserva: a Laravel-native observability and instrumentation runtime built for vendor neutrality, low overhead, and OpenTelemetry-aligned abstractions.

This release is about **architecture and quality**, not production APM yet. You get a strict monorepo, six Composer packages with enforced boundaries, a working instrumentation scaffold, and enterprise-grade CI so every future feature ships on solid ground.

## What's included

### Packages

- **`obeserva/contracts`** — Vendor-neutral span, trace context (W3C `traceparent`), and driver interfaces
- **`obeserva/core`** — Tracer, span lifecycle, context manager, always-on and probability samplers
- **`scout/laravel`** — Service provider, config, HTTP trace middleware scaffold, facade
- **`obeserva/scout-driver`** & **`obeserva/otel-driver`** — Adapter scaffolds for future roadmap work
- **`obeserva/testing`** — `FakeTracer` and span assertion helpers

### Tooling & CI

- PHPStan (max), Laravel Pint, PHPUnit, Rector, Infection
- Laravel 11–13 × PHP 8.3–8.5 compatibility matrix
- Security audit, coverage, benchmarks, fresh Laravel install validation
- Local `composer ci` and `composer pre-push` scripts

### Requirements

- PHP ^8.3 (8.3, 8.4, 8.5 tested)
- Laravel ^11.0 | ^12.0 | ^13.0 for `scout/laravel`

## What this release is not

v0.1.0 does **not** include database query tracing, queue propagation, Horizon/Octane instrumentation, or live Scout/OpenTelemetry export. Those land in v0.3.x–v0.6.x per the roadmap. The default driver is `noop`; HTTP middleware establishes request spans when enabled.

## Try it

```bash
composer require scout/laravel
php artisan vendor:publish --tag=obeserva-config
```

Set `OBESERVA_ENABLED=true` and inspect HTTP middleware behavior in a fresh Laravel app. For monorepo development:

```bash
git clone git@github.com:zaeem2396/laravel-obeserva.git
cd laravel-obeserva
composer install
composer ci
```

## What's next

**v0.2.0** focuses on the core runtime (span lifecycle engine) and deeper Laravel HTTP instrumentation. **v0.3.x** adds database and queue tracing—the problems that matter most for real Laravel observability.
