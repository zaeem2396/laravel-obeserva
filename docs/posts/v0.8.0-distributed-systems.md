# Obeserva v0.8.0 — Distributed Systems (Preview)

**Target release:** v0.8.0  
**Install:** `composer require scout/laravel`

---

## Summary

**v0.8.0 — Distributed Systems** extends Obeserva beyond queue propagation into Laravel events, notifications, broadcasts, and cross-service correlation IDs — keeping trace continuity across async workflows and microservice boundaries.

## Highlights

### Unified trace carriers

`TraceCarrierBag` and `W3cTracePropagator` centralize W3C `traceparent` injection and extraction. Queue payloads, events, and broadcasts share the same carrier format, including optional `correlation_id`.

### Event propagation

`TracePropagatingEventDispatcher` wraps Laravel's event dispatcher to:

- Inject active trace context into application events (via `InteractsWithTraceContext`)
- Restore parent context when handling propagated events
- Record `event.dispatch:{EventName}` spans for application events

Framework events (`Illuminate\*`) are excluded from instrumentation overhead.

### Notifications and broadcasts

- `TraceNotificationListener` records `notification.send` and `notification.sent` spans with channel metadata
- `TraceBroadcastListener` records `broadcast.dispatch` spans and propagates context into broadcastable events that use `InteractsWithTraceContext`

### Cross-service correlation

- Incoming HTTP requests resolve `X-Correlation-ID` (configurable) into `CorrelationContextStorage`
- Outbound HTTP responses echo the correlation ID when enabled
- Queue payloads and event carriers include `correlation_id` for worker continuity
- Spans expose `correlation.id` and `trace.id` attributes

## Configuration

| Variable | Default | Description |
|----------|---------|-------------|
| `OBESERVA_EVENT_PROPAGATION` | `true` | Inject trace context into dispatched application events |
| `OBESERVA_EVENT_TRACING` | `true` | Record spans for application event dispatch |
| `OBESERVA_NOTIFICATION_TRACING` | `true` | Record notification send/sent spans |
| `OBESERVA_BROADCAST_TRACING` | `true` | Record broadcast dispatch spans |
| `OBESERVA_BROADCAST_PROPAGATION` | `true` | Inject trace context into broadcastable events |
| `OBESERVA_CORRELATION_ENABLED` | `true` | Enable correlation ID resolution and propagation |
| `OBESERVA_CORRELATION_HEADER` | `X-Correlation-ID` | HTTP header name for correlation IDs |
| `OBESERVA_CORRELATION_PROPAGATE` | `true` | Echo correlation ID on HTTP responses |

Config keys: `obeserva.events.*`, `obeserva.notifications.*`, `obeserva.broadcasts.*`, `obeserva.correlation.*`.

## Example

```php
use Obeserva\Laravel\Events\Concerns\InteractsWithTraceContext;

final class OrderPlaced
{
    use InteractsWithTraceContext;

    public function __construct(public int $orderId) {}
}

// Dispatched during an HTTP request — context is injected automatically
event(new OrderPlaced(1001));
```
