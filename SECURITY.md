# Security Policy

## Supported versions

| Version | Supported |
|---------|-----------|
| 1.0.x | Yes |
| 0.9.x | Yes |
| 0.8.x | Yes |
| 0.7.x | Security fixes only |
| 0.6.x and earlier | No |

## Reporting a vulnerability

Please report security issues privately by opening a [GitHub Security Advisory](https://github.com/zaeem2396/laravel-obeserva/security/advisories/new) or emailing the repository maintainer.

Do not open public issues for security vulnerabilities.

We aim to acknowledge reports within 72 hours.
